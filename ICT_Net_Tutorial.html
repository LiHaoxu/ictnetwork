1.1

第一步 · 在 Mac 上

认清两张网

确认 Mac 上的两块网卡各是哪一块，默认出口是 Wi-Fi，以及当前连的 Wi-Fi 确实是 C2704。

两块网卡的接口名在开头已经查到：Wi-Fi 是 ‹Wi-Fi网卡›，USB 网卡是 ‹有线网卡›。USB 网卡在「系统设置 → 网络」里叫 ‹有线服务名›。USB 网卡换一个口或换一块，编号会变，变了就改参数里的「有线网卡」。

让 Wi-Fi 排在有线前面

打开「系统设置 → 网络」，点右下角的「…」，选「设定服务顺序」，把 Wi-Fi 拖到 ‹有线服务名› 上面。两张网同时在线时，排在前面的那一张是默认出口。

Mac 终端核对顺序
networksetup -listnetworkserviceorder | sed -n '1,6p'
应看到
An asterisk (*) denotes that a network service is disabled.
(1) Wi-Fi
(Hardware Port: Wi-Fi, Device: ‹Wi-Fi网卡›)

(2) ‹有线服务名›
(Hardware Port: ‹有线服务名›, Device: ‹有线网卡›)

括号里的 Hardware Port 是硬件自己的名字，通常和服务名相同。改过服务名的话两处会不一样，不影响后面的步骤。

确认连的是 C2704

macOS 有时不显示 Wi-Fi 的名称，名字也可能被同名热点冒用。更可靠的办法是看网络自身的四项特征。

Mac 终端默认出口、Wi-Fi 的地址、网关的 MAC
route -n get default | grep -E 'gateway:|interface:'
ifconfig ‹Wi-Fi网卡› | grep 'inet '
arp -n 10.158.13.254
在 C2704 应看到

  interface: ‹Wi-Fi网卡›
	inet 10.158.13.x netmask 0xffffff00 broadcast 10.158.13.255

DHCP 分给 Mac 的最后一段地址会变，不算特征。四项都对上，才是 C2704。1.6 里的后台任务用的也是这四项。

装上 Clash 分流规则

让进入 Clash 的连接按目标分路：所内站点走网线，模型服务走代理出口，国内站点、内网和 Tailscale 直连。

先确认 Clash 的三项设置

在 Clash Verge 里：系统代理开启，模式选「规则」，TUN 关闭。混合端口就是参数里的代理端口 ‹代理端口›。

Mac 终端系统代理是否指向 Clash
scutil --proxy | grep -E 'HTTPS?(Enable|Proxy|Port)'
应看到
  HTTPEnable : 1
  HTTPPort : ‹代理端口›

  HTTPSEnable : 1
  HTTPSPort : ‹代理端口›

装上脚本

  1. 打开 Clash Verge，进入「订阅」，打开「全局扩展脚本」。
  2. 把原有内容复制出来另存一份，比如存成同目录下的 Script.js.bak。
  3. 用下面的脚本整段替换，保存。
  4. 回到「订阅」页，执行「重新激活订阅」。只保存不激活，运行中的内核仍在用旧规则。
Clash Verge 的全局扩展脚本Script.js
function main(config) {
  const wired = "ICT-Wired";
  const campus = "ICT-Auto";
  const proxies = config.proxies || [];
  const groups = config["proxy-groups"] || [];
  const originalRules = config.rules || [];
  const catchAll = originalRules.find(rule => /^MATCH,/i.test(rule));
  const publicExit = catchAll && catchAll.split(",")[1];

  config.proxies = [
    { name: wired, type: "direct", "interface-name": "‹有线网卡›" },
    ...proxies.filter(proxy => proxy.name !== wired)
  ];
  config["proxy-groups"] = [
    ...groups.filter(group => group.name !== campus),
    {
      name: campus,
      type: "fallback",
      proxies: [wired, "DIRECT"],
      url: "http://captive.apple.com/hotspot-detect.html",
      "expected-status": "200-399",
      interval: 30,
      timeout: 2500,
      lazy: false
    }
  ];
  const routing = [
    "DOMAIN-SUFFIX,ict.ac.cn," + campus,
    "IP-CIDR,10.156.151.0/24," + campus + ",no-resolve",
    "IP-CIDR,159.226.39.22/32," + campus + ",no-resolve",
    "DOMAIN-SUFFIX,ts.net,DIRECT",
    "IP-CIDR,100.64.0.0/10,DIRECT,no-resolve",
    "IP-CIDR6,fd7a:115c:a1e0::/48,DIRECT,no-resolve",
    "IP-CIDR,10.0.0.0/8,DIRECT,no-resolve",
    "IP-CIDR,172.16.0.0/12,DIRECT,no-resolve",
    "IP-CIDR,192.168.0.0/16,DIRECT,no-resolve",
    "IP-CIDR,127.0.0.0/8,DIRECT,no-resolve",
    "IP-CIDR,169.254.0.0/16,DIRECT,no-resolve",
    "IP-CIDR6,fc00::/7,DIRECT,no-resolve",
    "IP-CIDR6,fe80::/10,DIRECT,no-resolve",
    "DOMAIN-SUFFIX,local,DIRECT"
  ];
  if (publicExit && !["DIRECT", "REJECT"].includes(publicExit)) {
    routing.push("GEOSITE,google," + publicExit, "GEOSITE,openai," + publicExit);
  }
  routing.push("GEOSITE,cn,DIRECT", "GEOIP,CN,DIRECT");
  config.rules = [...routing, ...originalRules.filter(rule => !routing.includes(rule))];
  return config;
}

文件在 ~/Library/Application Support/io.github.clash-verge-rev.clash-verge-rev/profiles/Script.js。

其余订阅原有规则不变，最后由订阅自己的 MATCH 规则接手
  • 代理出口的名字不用手写。脚本读订阅里 MATCH 规则指向的出口组，换订阅后不用改。
  • ICT-Auto 每 30 秒探测一次。探测返回 200 到 399 都算可用。有线还没认证时，探测会被重定向到认证页，仍然算可用，所以认证页本身能从网线打开。
  • 换了 USB 网卡要改接口名。脚本里的 ‹有线网卡› 来自参数。换了网卡先改参数，再把脚本重新复制一遍。有线网段不同的工位，把 10.156.151.0/24 换成自己的网段。
  • 规则只管进入 Clash 的连接。浏览器等读系统代理的应用自动分流。TUN 关闭时，裸 IP、普通 SSH 和 ping 不经过 Clash，按系统路由走。

function claude() (
    # Direct connections to the Anthropic API return 403 from this network; route through Clash.
    if /usr/bin/nc -z -G 1 127.0.0.1 ‹代理端口› 2>/dev/null; then
        export http_proxy='http://127.0.0.1:‹代理端口›'
        export https_proxy="$http_proxy" HTTP_PROXY="$http_proxy" HTTPS_PROXY="$http_proxy"
        export no_proxy='localhost,127.0.0.1,::1' NO_PROXY='localhost,127.0.0.1,::1'
        unset all_proxy ALL_PROXY
    else
        print -u2 -- '未检测到 127.0.0.1:‹代理端口› 代理（Clash 未开启？），claude 将直连，可能返回 403。'
    fi
    command claude "$@"
)
# <<< claude-proxy <<<
  • 函数体用圆括号。整个函数在子 shell 里运行，函数返回后，当前终端里不留下任何代理变量，目录也不会变。
  • 大小写两组变量都设。不同工具认的写法不同。
  • 回环地址不走代理。工具访问自己在本机起的服务时直接连。codex-proxy 会保留原有的 no_proxy，合并后去重。
  • 清掉 all_proxy。避免以前留下的 SOCKS 设置盖过这里的 HTTP 代理。
  • builtin cd 那一行。给 Codex 的新会话一个默认工作目录，来自参数里的「Codex 工作目录」，没填时是 Mac 主目录。
  • command 调用真正的程序。claude 这个函数与程序同名，靠它避免自己调用自己。
  • claude 多一步端口探测。Clash 没开时给出提示，仍然照常启动。函数里的注释写了原因：在这个网络直连 Anthropic 的接口会返回 403。

function codex-proxy2() (
    # The whole-machine VPN provides the network tunnel; do not chain through Clash.
    local vpn_state
    vpn_state=$(/usr/sbin/scutil --nc status ‹VPN服务编号› 2>/dev/null)
    if [[ "${vpn_state%%$'\n'*}" != "Connected" ]]; then

        return 1

    local proxy_bypass_item
    proxy_bypass_items=( "${(@s:,:)no_proxy}" "${(@s:,:)NO_PROXY}" localhost 127.0.0.1 ::1 )

1.6

第一步 · 在 Mac 上

让 Tailscale 在 C2704 下跟随系统代理

Tailscale 节点之间的数据走它自己的隧道，1.3 已经让这部分绕开 Clash。客户端自己连控制服务器和中继用的是 HTTPS，在 C2704 上要让这部分走 Clash。

Mac App Store 版的 Tailscale 从 1.88.1 起有一项偏好 UseSystemProxy，打开后控制连接、DERP 中继和部分 HTTPS 请求跟随系统代理。实测的结果是：打开之前，在所内对另一台节点 ping 两次都超时；打开之后经 DERP 连通。

这项偏好不适合一直开着。离开 C2704，或者 Clash 没开，Tailscale 会指向一个用不了的代理。所以用一个登录用户级的后台任务每 5 秒检查一次，自动开关。

适用范围和影响。只适用于 Mac App Store 版 Tailscale。任务只改 UseSystemProxy 这一个键，并在它变化时让已连接的 Tailscale 重连一次。它不写系统代理，不改路由，也不动 Clash。

"""Per-user Tailscale UseSystemProxy switch. No system proxy or route writes."""

BASE = Path.home() / "Library/Application Support/TailscaleNetworkProxy"
LABEL = "local.tailscale-network-proxy"

KEY = "UseSystemProxy"
APP_DOMAIN = "io.tailscale.ipn.macos"
GROUP = "W5364U7YZB.group.io.tailscale.ipn.macos"
APP_PREF = Path.home() / "Library/Containers" / APP_DOMAIN / "Data/Library/Preferences" / (APP_DOMAIN + ".plist")
SHARED_PREF = Path.home() / "Library/Group Containers" / GROUP / "Library/Preferences" / (GROUP + ".plist")
CACHE_PREF = APP_PREF.parent / (GROUP + ".plist")
TARGETS = [(APP_DOMAIN, APP_PREF), (str(CACHE_PREF.with_suffix("")), CACHE_PREF),
           (str(SHARED_PREF.with_suffix("")), SHARED_PREF)]
LOG = logging.getLogger(LABEL)
STOP = threading.Event()


def run(args, timeout=8, check=True):
    p = subprocess.run(args, text=True, capture_output=True, timeout=timeout,
                       env={**os.environ, "LC_ALL": "C", "LANG": "C"})
    if check and p.returncode:
        raise RuntimeError(f"{args[0]} {args[1:]} failed: {p.stderr.strip()}")
    return p.stdout.strip()


def read_json(path, default=None):
    try:
        return json.loads(path.read_text())
    except FileNotFoundError:
        return default


def atomic_json(path, value):
    temp = path.with_suffix(".tmp")
    temp.write_text(json.dumps(value, ensure_ascii=False, indent=2) + "\n")
    os.chmod(temp, 0o600)
    temp.replace(path)


def pref_value(path):
    try:
        return plistlib.loads(path.read_bytes()).get(KEY)
    except FileNotFoundError:
        return None


def setting_values():
    return {str(p): pref_value(p) for _, p in TARGETS}


def write_settings(value):
    # The shared container is essential on this installed App Store build.
    # defaults uses cfprefsd and modifies only this key, preserving all others.
    for domain, path in TARGETS:
        if pref_value(path) is not value:
            run(["/usr/bin/defaults", "write", domain, KEY, "-bool", str(value).lower()])
    if any(pref_value(p) is not value for _, p in TARGETS):
        raise RuntimeError("UseSystemProxy read-back verification failed")


def read_network():
    route = run(["/sbin/route", "-n", "get", "default"], check=False)
    def field(name):
        m = re.search(r"^\s*" + name + r":\s*(\S+)", route, re.M)
        return m.group(1) if m else ""
    interface, gateway = field("interface"), field("gateway")
    result = {"interface": interface, "gateway": gateway, "address": "", "mask": "", "gateway_mac": ""}
    if not re.fullmatch(r"en\d+", interface):
        return result
    info = run(["/sbin/ifconfig", interface], check=False)
    m = re.search(r"\binet (\d+\.\d+\.\d+\.\d+) netmask (0x[0-9a-f]+)", info)
    if m:
        result["address"] = m.group(1)
        result["mask"] = str(ipaddress.IPv4Address(int(m.group(2), 16)))
    try:
        ipaddress.IPv4Address(gateway)
    except ValueError:
        return result
    arp = run(["/usr/sbin/arp", "-n", gateway], check=False)
    mac = re.search(r"\bat ([0-9a-f:]+) on " + re.escape(interface) + r"\b", arp, re.I)
    if mac:
        result["gateway_mac"] = ":".join(part.zfill(2) for part in mac.group(1).lower().split(":"))
    return result


def matches(network, config):
    try:
        subnet = ipaddress.IPv4Network(config["subnet"])
        observed = ipaddress.IPv4Network(f"{network['address']}/{network['mask']}", strict=False)
        return (network["interface"] == config["interface"] and observed == subnet
                and network["gateway"] == config["gateway"]
                and network["gateway_mac"] == config["gateway_mac"])
    except (ValueError, KeyError):
        return False


def proxies_match(text, config):
    def value(key):
        m = re.search(r"^\s*" + re.escape(key) + r" : (\S+)", text, re.M)
        return m.group(1) if m else ""
    return (value("ProxyAutoConfigEnable") != "1" and value("ProxyAutoDiscoveryEnable") != "1"
            and all(value(prefix + "Enable") == "1"
                    and value(prefix + "Proxy") == config["proxy_host"]
                    and value(prefix + "Port") == str(config["proxy_port"])
                    for prefix in ("HTTP", "HTTPS")))


def inspect(config):
    network = read_network()
    ict = matches(network, config)
    # Populate only the verified candidate gateway's ARP entry after wake/link changes.
    if (not ict and network["interface"] == config["interface"]
            and network["gateway"] == config["gateway"] and not network["gateway_mac"]):
        run(["/sbin/ping", "-n", "-c", "1", "-W", "200", "-t", "1", config["gateway"]],
            timeout=2, check=False)
        network = read_network()
        ict = matches(network, config)
    system_proxy_ok = proxies_match(run(["/usr/sbin/scutil", "--proxy"]), config)
    ready = False
    if ict and system_proxy_ok:
        try:
            # AF_INET + numeric address avoids macOS getaddrinfo delays during a link change.
            with socket.socket(socket.AF_INET, socket.SOCK_STREAM) as probe:
                probe.settimeout(0.5)
                probe.connect((config["proxy_host"], config["proxy_port"]))
                ready = True
        except OSError:
            pass
    override = read_json(BASE / "override.json", {})
    enabled = ict and system_proxy_ok and ready and override.get("mode") != "normal"
    reason = ("manual-normal" if override.get("mode") == "normal" else
              "outside-ict" if not ict else "system-proxy-mismatch" if not system_proxy_ok else
              "clash-unavailable" if not ready else "ict")
    return {"network": network, "ict_network": ict, "system_proxy_matches_clash": system_proxy_ok,
            "clash_reachable": ready, "desired_proxy": enabled, "reason": reason}


def vpn_status(config):
    return run(["/usr/sbin/scutil", "--nc", "status", config["vpn_service"]], check=False).split("\n")[0]


def restart_vpn(config, state):
    # This uses Apple's VPN service lifecycle, never 'up --reset' or a new login.
    # Persist the intent so a watcher crash after stop cannot strand the VPN off.
    state["pending_reconnect"] = True
    atomic_json(BASE / "state.json", state)
    run(["/usr/sbin/scutil", "--nc", "stop", config["vpn_service"]])
    for _ in range(20):
        if vpn_status(config) == "Disconnected":
            break
        time.sleep(0.25)
    run(["/usr/sbin/scutil", "--nc", "start", config["vpn_service"]])
    state["pending_reconnect"] = False
    state["last_reconnect"] = dt.datetime.now().astimezone().isoformat(timespec="seconds")
    LOG.info("Tailscale VPN restarted to apply UseSystemProxy=%s", state["desired_proxy"])


def reconcile(config):
    with (BASE / "apply.lock").open("a") as lock:
        fcntl.flock(lock, fcntl.LOCK_EX)
        previous = read_json(BASE / "state.json", {})
        try:
            state = inspect(config)
        except Exception as error:
            # Unknown network: turn off proxy instead of preserving stale institute mode.
            state = {"desired_proxy": False, "reason": "detection-error", "error": str(error)}
        want = state["desired_proxy"]
        changed = any(pref_value(path) is not want for _, path in TARGETS)
        state["checked_at"] = dt.datetime.now().astimezone().isoformat(timespec="seconds")
        state["last_reconnect"] = previous.get("last_reconnect")
        state["pending_reconnect"] = previous.get("pending_reconnect", False)

第二步 · 登录服务器，让它拉得到 GitHub

第二步 · 先看懂

流量怎么走

现象：能登录，却拉不下代码

登录时，连接从 Mac 发往服务器。执行 git clone 时，Git 进程在服务器上运行，要由服务器自己去连 GitHub。在不能直连外网的内网服务器上，这一跳在 TCP 握手阶段就超时了，还没走到仓库权限那一步。Mac 的处境不同：它连得上内网，也能经代理访问 GitHub。

解法：让请求沿 SSH 连接回头

SSH 连接建立后，可以在里面再开一条反方向的通道：服务器上的程序连接服务器自己的一个端口，数据就沿这条 SSH 连接回到 Mac。让 Git 把请求交给这个端口，再由 Mac 上的代理替它连 GitHub。服务器从头到尾只连自己的 127.0.0.1。

完整路径：一次 git clone 经过的七个环节

  1. Git 读到一条只对 github.com 生效的代理设置，连接服务器自己的 127.0.0.1:‹转发端口›，发出 CONNECT github.com:443。
  2. 这个端口由 sshd 代为监听。sshd 把连进来的连接装进已有的 SSH 连接，送回 Mac。
  3. Mac 上的 ssh 把它接到一个 Unix 套接字 ~/.ssh/gh-‹别名›.sock。
  4. 守在套接字后面的转发脚本检查目标，只放行 github.com:443，其余一律回 403。
  5. 脚本向本机的 127.0.0.1:‹代理端口› 再发一次 CONNECT。这是 Clash 的端口。
  6. Clash 按规则选出口，连到 github.com:443。
  7. 两个 200 依次返回后，Git 与 GitHub 直接做 TLS 握手。此后中间各环节只搬运密文。

两个 127.0.0.1。127.0.0.1:‹转发端口› 在服务器上，127.0.0.1:‹代理端口› 在 Mac 上。127.0.0.1 指的是本机，所以这两个地址分属两台机器，互不相干。

第二步 · 原理，可以跳过

三组配置各管什么

2.5 加的六行分成三组，各自对应一个东西的生命周期。图 10 是一次从登录到退出的过程。

  • ControlMaster、ControlPath、ControlPersist。第一次 ssh ‹别名› 完成认证后，这条连接成为主连接，在 ~/.ssh 下留一个以 cm- 开头的控制套接字。之后的终端窗口和 VS Code 发现它，就直接复用，不再认证。最后一个窗口关闭后，主连接再等 2 分钟才退出。
  • RemoteForward。主连接建立时，请服务器上的 sshd 监听 127.0.0.1:‹转发端口›。主连接一退出，这个监听立刻消失。
  • LocalCommand。主连接建立时，在 Mac 上执行一次脚本。脚本把自己放到后台，每 15 秒看一眼控制套接字。套接字没了，它就删掉自己的 .sock 并退出。

为什么 Control 三行不能省。实测去掉连接复用后，脚本找不到控制套接字，15 秒后自行退出，服务器上的请求随即报 Connection reset by peer。

第二步 · 原理，可以跳过

脚本为什么是一道闸门

Git 通过代理访问 HTTPS 站点时，先发一句 CONNECT 主机:端口，请代理帮忙接通，接通后再在这条连接里做 TLS 握手。脚本只看这一句。

为什么不把端口直接转到代理

更省事的做法是把服务器的 ‹转发端口› 直接转发到 Mac 的 ‹代理端口›，不要脚本。问题在于服务器是多人共用的：127.0.0.1:‹转发端口› 这个地址，同一台服务器上的任何用户、任何程序都能连。直接转发相当于把你的代理开放给所有人，目标也不受限制，包括你的 Mac 能到的内网地址。加上脚本后，能通过的目标只剩 github.com:443。

第二步 · 原理，可以跳过

谁能看到什么

  • 代码内容和 GitHub 凭据。在 Git 与 GitHub 之间的 TLS 里，只有两端能读。证书校验由服务器上的 Git 完成，中间环节冒充不了 GitHub。
  • 脚本、Clash、代理节点。知道有一条连接要去 github.com:443，看得到流量大小和时间，读不到内容。
  • 服务器上的其他用户。连得上 127.0.0.1:‹转发端口›，可以借它访问 GitHub，流量算在你的代理上。他们看不到你的数据，也去不了别的地址。
  • Mac 上的套接字。脚本用 umask 077 创建，只有你自己的账号能连。

第二步 · 原理，可以跳过

aTrust 与 Clash 的分工

aTrust 和 Clash 能同时开着，是因为它们工作在不同的层面，管的流量不重叠。

  • 路由表，按目的 IP 分。aTrust 登录后，去服务器地址的路由指向它的虚拟网卡，名字以 utun 开头。ssh 不读系统代理设置，直接按路由表走，所以去 ‹服务器地址› 的连接进了 aTrust 隧道。在 Mac 上执行 route -n get ‹服务器地址›，能看到它走的是哪块网卡。
  • Clash，按域名规则分。浏览器等应用读系统代理设置，把连接交给 127.0.0.1:‹代理端口›。转发脚本不看系统设置，直接连这个端口。Clash 再按规则决定直连还是走代理节点。

Clash 的 TUN 模式会接管路由表，可能与 aTrust 的路由冲突。本文的实测组合里 TUN 是关闭的。分流规则本身在 1.3。

"""Serve GitHub HTTPS CONNECT requests through the Mac's existing HTTP proxy."""
import asyncio
import fcntl
import os
from pathlib import Path
import subprocess
import sys


SOCKET = Path(__file__).with_suffix(".sock")
DESTINATION = b"github.com:443"


async def copy_stream(reader, writer):
    while chunk := await reader.read(65536):
        writer.write(chunk)
        await writer.drain()
    if writer.can_write_eof():
        writer.write_eof()


async def handle(client, response):
    upstream = None
    try:
        headers = await asyncio.wait_for(client.readuntil(b"\r\n\r\n"), 8)
        request = headers.split(b"\r\n", 1)[0].split()
        if len(request) != 3 or request[0] != b"CONNECT" or request[1].lower() != DESTINATION:
            response.write(b"HTTP/1.1 403 Forbidden\r\nConnection: close\r\n\r\n")
            await response.drain()
            return
        inbound, upstream = await asyncio.wait_for(asyncio.open_connection("127.0.0.1", ‹代理端口›), 5)
        upstream.write(b"CONNECT github.com:443 HTTP/1.1\r\nHost: github.com:443\r\n\r\n")
        await upstream.drain()
        status = await asyncio.wait_for(inbound.readuntil(b"\r\n\r\n"), 15)
        if status.split(b"\r\n", 1)[0].split()[1:2] != [b"200"]:
            raise ConnectionError("Upstream proxy rejected the connection")
        response.write(b"HTTP/1.1 200 Connection Established\r\n\r\n")
        await response.drain()
        await asyncio.gather(copy_stream(client, upstream), copy_stream(inbound, response))
    except (OSError, EOFError, asyncio.TimeoutError, asyncio.LimitOverrunError):
        pass
    finally:
        if upstream is not None:
            upstream.close()
        response.close()


async def serve(control_socket):
    # Lock the helper itself so overlapping SSH connections share one listener.
    with open(__file__, "rb") as lock:
        try:
            fcntl.flock(lock, fcntl.LOCK_EX | fcntl.LOCK_NB)
        except BlockingIOError:
            return
        if SOCKET.is_socket():
            SOCKET.unlink()
        server = await asyncio.start_unix_server(handle, path=str(SOCKET))
        try:
            async with server:
                while True:
                    await asyncio.sleep(15)
                    if not control_socket.is_socket():
                        break
        finally:
            SOCKET.unlink(missing_ok=True)


if __name__ == "__main__":
    os.umask(0o077)
    if sys.argv[1] == "--serve":
        asyncio.run(serve(Path(sys.argv[2])))
    else:
        subprocess.Popen([sys.executable, __file__, "--serve", sys.argv[1]],
                         stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL,
                         stderr=subprocess.DEVNULL, start_new_session=True)
PYEOF

位置作用
第 10–11 行套接字与脚本同目录、同名，扩展名换成 .sock。唯一放行的目标是 github.com:443。
copy_stream把一端读到的字节原样写到另一端。
handle读请求的第一行。不是 CONNECT github.com:443 就回 403。否则连本机代理端口，向它发 CONNECT，收到 200 后回一个 200，然后双向搬运字节。
serve对脚本文件加锁，保证同一份脚本只有一个实例在监听。每 15 秒检查主连接的控制套接字，不在了就删掉自己的套接字并退出。
末尾 8 行umask 077 让套接字只有本人能访问。被 LocalCommand 调用时，把真正的服务进程放到后台后立即返回，不拖慢登录。
